# Number Formatting

## Purpose

Create consistent numeric representation throughout Fermor.

## Dashboard

Use compact notation where space is limited.

Examples:

₹18.4L
₹11.2L
₹2.4L

## Detail Views

Use more precise values when required.

Examples:

₹18,40,000
₹11,20,000
₹2,40,000

## Percentages

Dashboard trend format:

↑ 6.2%
↓ 3.1%

Accessible meaning must not depend only on direction or color.

Use semantic text where necessary:

"Increased 6.2%"

"Decreased 3.1%"

## Decimal Places

Do not display unnecessary precision.

Prefer:

18.4%

instead of:

18.437291%

unless precision is meaningful.

## Zero

Use:

0

Do not replace zero with ambiguous symbols.

## Missing Data

Never invent a numeric value.

Use:

Not available

or an appropriate empty state.

Do not use:

₹0

when the actual value is unknown.

## Negative Values

Use clear negative notation.

Example:

-₹3,200

or the established financial formatting system.

Do not rely only on red color to communicate negative values.
