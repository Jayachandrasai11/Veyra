# Currency Rules

## Primary Currency

Fermor uses the Indian Rupee symbol:

₹

## Compact Financial Values

Use Indian numbering conventions.

Examples:

₹18.4L
₹8L
₹2.5Cr

## Detailed Values

Use Indian digit grouping.

Examples:

₹18,40,000
₹8,00,000
₹2,50,000

## Currency Placement

Use:

₹50,000

Not:

50,000₹

## Currency + Text

Good:

Monthly contribution
₹50,000

Good:

Target
₹20L

Avoid unnecessarily repeating the currency symbol in every sentence.

## Unknown Currency

Do not assume a currency if the source data does not establish one.

## Mixed Currencies

Clearly identify the currency when multiple currencies are present.

## Rounding

Dashboard:
→ Compact and readable

Detailed financial views:
→ Preserve meaningful precision

Never round values in a way that materially changes the user's financial understanding.
