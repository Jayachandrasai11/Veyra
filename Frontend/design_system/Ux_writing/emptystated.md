# Empty State Copy

## Purpose

Empty states explain why content is absent and provide a useful next action.

## General Structure

Explanation
→ Context
→ CTA

## No Accounts

No accounts connected yet.

Connect your accounts to see
your complete financial picture.

[Connect accounts]

## No Goals

No goals yet.

Create a goal and let Fermor
help you stay on track.

[Create a goal]

## No Insights

Nothing needs your attention right now.

Fermor will let you know when
something important changes.

## Empty State Rules

Do:

- Explain why content is missing
- Give the user a useful next step
- Keep the tone calm
- Avoid making the product feel broken

Do not:

- Show meaningless empty cards
- Use "N/A" everywhere
- Say "Nothing here"
- Blame the user
- Invent placeholder financial data

## New User

A new user should receive an actionable setup path.

Empty
→ Explanation
→ CTA
→ Setup

## Partial Data

Do not use an empty state when some data exists.

Use the Partial Data state instead.
