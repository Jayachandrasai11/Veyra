# Navigation Language

## Primary Navigation

Use exactly:

- Home
- Insights
- Goals
- Explore

## Rules

Navigation labels must:

- Be short
- Be recognizable
- Use consistent terminology
- Describe destinations
- Avoid unnecessary adjectives

Good:

Home
Insights
Goals
Explore

Bad:

Financial Dashboard
Personalized Financial Insights
Financial Goal Management
Financial Tools & Education

## Navigation Destination Rules

Home
→ /home

Insights
→ /insights

Goals
→ /goals

Explore
→ /explore

## Mobile

Mobile navigation may use the same labels.

Do not create different terminology for mobile unless space requires an accepted abbreviation.

## Active Navigation

The active navigation item must use the same label as the destination.

Do not rename the active page dynamically.

## Navigation Accessibility

Navigation labels must remain understandable without relying on icons.
