# Confirmation Copy

## Purpose

Sensitive or destructive financial actions require explicit confirmation.

## Actions Requiring Confirmation

Examples:

- Delete account
- Remove financial account
- Disconnect account
- Delete goal
- Remove important financial data
- Irreversible financial actions

## Confirmation Structure

Title
+
Consequence
+
Cancel
+
Confirm action

## Example

Remove account?

Your transactions from this account will
no longer be included in your financial picture.

[Cancel] [Remove account]

## Destructive Action Labels

The confirmation action should describe the action.

Good:

Remove account

Delete goal

Disconnect account

Bad:

Confirm

Yes

Okay

Continue

## Avoid Fear

Do not exaggerate consequences.

State the actual consequence clearly.

## Cancel

Cancel should always remain available for reversible confirmation dialogs unless the action is already committed.

## Confirmation Before Action

Do not perform a destructive action before confirmation.

## Financial Context

When an action affects financial calculations, explain the impact.

Example:

"Removing this account will change your Net Worth and Financial Health calculations."

## No Confirmation Spam

Do not ask for confirmation for harmless, reversible actions.

Use confirmations when the consequence justifies the interruption.
