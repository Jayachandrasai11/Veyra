# Button Language

## Purpose

Buttons describe actions.

## Primary Rule

Prefer:

Verb + object

Examples:

- Connect accounts
- Create goal
- View goal
- Understand spending
- See why
- Try again
- Reconnect account
- Add money
- Adjust target
- Edit goal

## Avoid

Do not use vague labels when a specific action is possible.

Avoid:

- Click here
- Submit
- Continue
- Okay
- Learn more
- Go
- Proceed

## Button Hierarchy

Every important interface should have a clear primary action.

Example:

[See what changed] [Ask Fermor]

The primary action must be visually and semantically clear.

## Loading

The button label may change to communicate processing.

Example:

Connect accounts
→ Connecting...

Try again
→ Retrying...

## Destructive Actions

Use explicit language.

Good:

Remove account

Delete goal

Disconnect account

Avoid:

Confirm

Proceed

Continue

## Button Labels

Keep labels concise.

Prefer 1–4 words when possible.

## Button Capitalization

Use sentence case.

Good:

Connect accounts

Create goal

Bad:

CONNECT ACCOUNTS

Create Goal
