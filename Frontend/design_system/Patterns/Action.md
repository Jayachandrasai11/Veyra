13 — AI + ACTION — IMPLEMENTATION RULES

1. Create AI + Action as a reusable pattern.

2. Structure:

   AI Identifier
   Insight
   Optional Explanation
   Primary Action
   Ask Fermor

3. Use it when Fermor provides:
   - Interpretation
   - Observation
   - Explanation
   - Anomaly
   - Decision support

4. Do not use AI treatment for ordinary
   financial metrics or raw data.

5. Primary action must be relevant to
   the specific insight.

6. Ask Fermor is the deeper conversational
   path, not always the primary action.

7. Preserve context when opening Ask Fermor.

8. Ask Fermor should know:
   - Source page
   - Current insight
   - Financial category
   - Relevant time period
   - Related goal/account when applicable

9. Do not overuse AI icons, sparkle icons,
   badges or gradients.

10. AI should feel calm, useful and trustworthy.

11. Do not present uncertain financial
    information as certain.

12. Use the global Fermor button system.

13. Use Lucide Icons.

14. Support loading, error and unavailable
    data states.

15. Follow the global Fermor motion system.

16. Keep the hierarchy:

    Insight
       ↓
    Explanation
       ↓
    Action
       ↓
    Ask Fermor
