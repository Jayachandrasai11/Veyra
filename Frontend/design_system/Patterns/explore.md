EXPLORE / QUICK ACTIONS — IMPLEMENTATION RULES

1. Name the overall component QuickActions.

2. Name each action QuickAction.

3. QuickActions is an action pattern,
   not a content-card pattern.

4. Use compact action buttons on Home.

5. Do not use four large cards on Home.

6. Home actions:
   Plan
   Compare
   Calculate
   Learn

7. Use Lucide Icons exclusively.

8. Do not use emoji.

9. Recommended icons:
   Plan → Route
   Compare → GitCompare
   Calculate → Calculator
   Learn → BookOpen

10. Icon + text should be used together.

11. Do not use icon-only buttons for these actions.

12. Use the existing Fermor Button system.

13. Prefer secondary/outline styling over
    four primary buttons.

14. Do not create custom button styling
    inside QuickAction.

15. Use consistent icon sizing.

16. Maintain consistent action heights.

17. Desktop:
    four actions horizontally.

18. Tablet:
    allow a 2×2 layout when necessary.

19. Mobile:
    use a comfortable 2×2 grid or
    vertically stacked actions.

20. Maintain minimum accessible touch targets.

21. Every action must have a clear destination.

22. Use semantic links when the action
    navigates to another page.

23. Use buttons when the action performs
    an in-place operation.

24. Don't disable actions unnecessarily.

25. Do not expose every Explore feature
    on Home.

26. Home should expose only the four
    top-level Explore categories.

27. Detailed tools belong inside Explore.

28. Use subtle hover/focus/active states.

29. Support keyboard navigation and
    visible focus states.

30. Avoid excessive motion.

31. Motion.dev may be used for subtle
    interaction transitions.

32. QuickActions should not visually compete
    with Financial Health, Insights, Goals,
    or Fermor Thought.

33. Maintain Fermor's calm, intelligent,
    minimal visual language.

DESIGN NOTES

• Explore on Home is a Quick Action pattern.

• It is not another dashboard card section.

• Home should expose:
  Plan
  Compare
  Calculate
  Learn

• Use compact buttons rather than large cards.

• Icon + label is preferred.

• Use Lucide icons.

• Keep icons visually secondary to labels.

• Use outline/secondary treatment.

• Avoid four primary buttons.

• Avoid excessive shadows and decoration.

• Home provides entry points.
  Explore provides the complete toolkit.

• Keep the action group visually lightweight.

• Don't expose every financial tool on Home.

• Maintain clear navigation destinations.

• Keep interaction subtle.

• Preserve Fermor's calm and trustworthy
  financial-product personality.
