```
# Fermor — Motion
```

\## Primary Library

Motion

\## Philosophy

Motion must be:

\- subtle

\- purposeful

\- consistent

\- fast

\- non-distracting

\## Approved Uses

Button feedback

Card elevation

Progress transitions

Number transitions

Drawer transitions

Modal transitions

AI streaming

Notification indicators

\## Do Not

Do not create unique animations for every component.

Do not use excessive:

\- bouncing

\- spinning

\- scaling

\- parallax

\- spring effects

\## Interaction Rule

Same interaction should use the same motion pattern throughout Fermor.

\## Reduced Motion

Respect prefers-reduced-motion.

Animations must not be required to understand content.
