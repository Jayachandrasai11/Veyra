```
# Fermor — Data Visualization
```

\## Primary Library

Recharts

\## Rules

Charts must communicate information clearly.

Do not use charts merely for decoration.

\## Financial Charts

Support:

\- trends

\- comparisons

\- allocation

\- progress

\- historical changes

\## Accessibility

Do not communicate meaning through color alone.

Charts should provide accessible textual context where appropriate.

Example:

Spending increased 18% this month.

The chart provides visual detail; the text provides semantic meaning.

\## Formatting

Use Fermor:

\- currency

\- percentage

\- date

\- number

rules.

\## Empty

Never render an empty chart with meaningless axes.

Use an appropriate empty state.
