\## Validation

Use Zod schemas for structured validation.

\## Rules

Validate clearly.

Do not wait until submission when immediate validation is useful.

Errors must explain:

What is wrong?

How can it be fixed?

\## Financial Inputs

Currency inputs must use Fermor currency formatting rules.

Example:

Monthly contribution

₹50,000

\## Accessibility

Every input must have:

\- label

\- accessible name

\- error association where applicable

\- keyboard support
