```
# Fermor — Icon Rules
```

\## Primary Icon Library

Use:

Lucide React

\## Rules

Do not mix multiple icon libraries.

Do not use emoji as UI icons.

Bad:

🔔

👤

⚙️

Use Lucide icons instead.

\## Icon Sizing

Use the established Fermor icon sizes.

Typical system:

\- 16px

\- 20px

\- 24px

Do not create arbitrary icon sizes.

\## Icon + Text

Icons should support meaning.

Do not add icons purely for decoration.

\## Accessibility

Decorative icons should be hidden from assistive technology.

Meaningful icons must have accessible labels.
